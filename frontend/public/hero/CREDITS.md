# Hero images

`sprocket-photo.jpg` and `sprocket-measured.jpg` are Re-Forge's own output (the rectified photo, and the same with
the measured outline, the mirror axis and the rebuilt region drawn on it) for the bundled example `broken-sprocket`.
That example is a synthetic composite of a real 21-tooth chain sprocket photographed by the user and supplied for the
examples: cut out, placed on a rendered mat, one side snapped off. Used with permission; no third-party licence.
